## 2. 核心模型变化

### 2.1 从「小时制 + 手动打分」到「清单制 + 自动得分」

| 维度 | Day 7 MVP（V1） | Day 8+ 增量（V2） |
|---|---|---|
| 触发节奏 | 每整点提醒 | 前一晚 23:00 提醒设任务（其他小时提醒**取消**） |
| 用户输入 | 每次打卡手动选 1-5 分 | 一次性设任务清单（含分值），勾选完成 |
| 完成度 | 已打卡次数 / 8 | 已完成任务的累计分值 / 100 |
| 用户改值粒度 | 每次打卡能改 | 任务清单 23:30 截止前可改，截止后只读 |
| 错误容忍 | 没有（写错就错） | 23:00-23:30 窗口内可增删改 |

### 2.2 数据模型 V2

```js
// 任务清单（按日期分）— 新
tb_tasks_v1: {
  'YYYY-MM-DD': {
    items: [
      { id, name, score, order, createdAt, updatedAt }
    ],
    totalScore: 100,         // 必须 = 100，否则视为无效
    lockedAt: ts | null      // 23:30 后锁定，null 表示可编辑
  }
}

// 打卡（完成任务的动作记录）— 新
tb_records_v2: [
  { id, taskId, ts, note }  // taskId 关联到 tb_tasks_v1
]

// 旧数据保留
tb_records_v1: [ ... ]      // 保留读权限，不再写
```

**关键约束**：
- `totalScore` 必须恒等 100（用户改分值时自动校验）
- 当日 23:30 之后 `lockedAt` 被设置，UI 进入只读模式
- 新打卡（records_v2）必须挂载到一个 taskId，不存在"无任务的打卡"

## 3. 业务流程

```
前一晚 23:00        23:00-23:30           23:30           第二天全天
   │                   │                  │                  │
   ▼                   ▼                  ▼                  ▼
[系统弹通知]      [用户编辑任务]      [锁定清单]      [勾选完成]
"该设明天任务了"   增/删/改/排序        不能再改        自动算完成度
"总分必须100"      实时校验总和        保存快照          日复盘
```

## 4. 本期新增功能清单

### F5 · 任务清单自设（前一晚 23:00-23:30）

- **入口**：通知引导 → P1 顶部"今晚任务清单（截止 23:30）"按钮
- **UI 形态**：列表 + 增/删按钮 + 每个任务的分值输入框 + 实时显示"当前总和 X / 100"
- **校验**：保存时若 ≠ 100，禁用保存按钮 + 提示原因
- **完成动作**：保存成功 → 弹一条确认通知 → 锁定清单

### F6 · 任务清单 CRUD（仅 23:00-23:30 窗口内）

- **增**：在列表末尾追加一行（默认分值 = 剩余可分配分值）
- **删**：每行右侧"×"按钮（至少保留 1 个任务）
- **改**：名称（input）输入和分值（input 1-100）输入实时校验
- **排序**：本期不做（任务顺序按创建时间）
- **拖拽**：本期不做

### F7 · 完成度自动计算（第二天）

- **触发**：勾选完成 → 自动累加 `score` → 完成度进度条 + 百分比
- **完成度角标**：P1 顶栏"今日 X / 100"（不是 0/8）
- **取消勾选**：支持（重新减分）

## 5. 与 Day 7 MVP 的兼容矩阵

| 元素 | Day 7 行为 | D8/D9 行为 | 兼容处理 |
|---|---|---|---|
| F1 每小时提醒 | 每小时一次 | **取消**，只保留 23:00 一次 | F1 调度器升级为「多触发场景」 |
| F2 手动打分 | 1-5 滑动条 | **取消** | UI 移除分数条 |
| F3 日视图 | 取最长一句备注 | 保留 + 加自动分析（#6） | 数据源兼容 |
| F4 localStorage | `tb_records_v1` | `tb_tasks_v1` + `tb_records_v2` | V1 保留读权限 |
| **P2 弹窗** | 分数 + 备注 | 改为"完成任务"勾选 + 可选备注 | UI 重写 |
| **页面顶栏角标** | 0/8（次数）| X/100（分数）| UI 改 |
